01 · 背景与痛点

托盘自动化系统示例 · 视频来自用户提供的 Fastems 参考资料

1

制造模式转型

随着产品定制化程度提高和生命周期缩短，生产模式正从少品种大批量转向多品种小批量。企业因此面临柔性自动化升级难题，而托盘自动化系统（PAS）是重要解决方案之一。

2

行业升级意愿强

Fastems 对中国托盘自动化应用的调查显示，78% 的受访企业计划在一至三年内升级 PAS。更高的产品多样性和更短的交付窗口，使 PAS 的高效运行成为日益重要的生产管理问题。

3

多资源高度耦合

工序选择、机器分配、夹具托盘占用、设置站装卸与物料托盘释放相互影响。一个局部选择会改变其他资源的可用时间和后续可行空间，使物理柔性无法自动转化为系统效率。

真正的瓶颈，是如何把系统的物理柔性转化为生产效率。

难点一

约束多

兼容选择、同步占用、先后衔接、等待与释放必须同时满足。

难点二

耦合强

机器选择会改变夹具占用；夹具选择也会改变机器等待。

难点三

规模增长快

资源和工件增加后，可行组合与决策空间迅速扩大。

03 · 研究现状

现有方法能优化生产，
但真正的多资源联合学习仍然少见。

研究方向主要决策RL 的作用
标准柔性作业车间工序 + 机器直接学习分配
多资源调度机器 + 运输 / 工人等多用于选择规则、算子或参数
已有 PAS 学习方法主要学习夹具托盘选择工序与机器仍由固定规则决定
本研究工序 + 夹具托盘 + 机器端到端联合决策

根据第五篇论文 “RL applications in FJSP and MRFJSP” 文献表归纳。

研究缺口从“让 RL 辅助算法”，走向“让 RL 直接端到端完成多资源调度”。

05 · AI 研究重点

先让智能体学会端到端联合决策，
再让 LLM 用反例推动策略持续改进。

强化学习 · End-to-End Q-Learning

一个动作，同时决定工序、夹具托盘和机器

候选筛选与三层离散化共同控制状态—动作规模，使相似调度情境能够共享经验；核心是在保留关键决策差异与避免 Q 表过度稀疏之间取得平衡。

工序×夹具托盘×机器→联合动作
01 · STATE

候选动作的状态表示

用装卸时间、加工时间、工序等待、机器等待、剩余工作量和工序柔性六个离散特征描述每个候选动作。

φₜ(a) = [bˡᵘᵗ, bᵖʳᵒᶜ, bᵒʷ, bᵐʷ, bʳᵉᵐ, bᶠˡᵉˣ]
02 · ACTION

端到端联合动作

先生成所有可行的工序—夹具托盘—机器组合，再保留兼顾装卸、加工和等待偏好的代表候选，由智能体完成最终选择。

aₜ = (Oᵢⱼ, f, m) ∈ Ãₜ
03 · REWARD

过程反馈 + 完工反馈

过程项惩罚本次动作造成的部分完工期增长；终止项评价完整调度相对参考方案的改善，并按案例规模归一化。

rₜ = (Cₜᵖ − Cₜ₊₁ᵖ)/Cʳᵉᶠ + Iₜβ(Cʳᵉᶠ − Cₘₐₓ)/Cʳᵉᶠ
04 · UPDATE

从当前结果修正长期价值

用即时回报与下一决策点的最佳估计共同更新 Q 值，使一次联合选择能够学习其对后续调度的影响。

Q ← Q + α[rₜ + γ max Q′ − Q]

结果 · 100 个测试案例

在覆盖完整测试集的比较方法中，智能体的平均 makespan 均更低

总体比较覆盖 GA、TS、SA 与多种规则组合。Gurobi 仅评估最小的 15 个案例，因此不纳入这项完整测试集结论。

极端测试暴露的边界

优势并不意味着覆盖所有分布变化

在装卸时间占主导的极端场景中，三层离散化会把差异明显的装卸时间映射到同一类别，造成信息损失；智能体平均比 Rule 2 差 3.39%。而在加工主导与资源数量减少场景中，智能体仍保持明显优势。

LLM Agent · Counterexample-driven Learning

LLM 不替代调度智能体，而是帮助它发现表示缺陷

Agent 从反事实决策中寻找“当前策略选了什么、换一个动作会怎样”，把错误转化为可证伪的特征假设，再由冻结的实验协议决定淘汰、晋级或结束。

LLM 生成假设→程序执行实验→证据决定去留
01

目标

消除有害同键反例，同时保持或改善整体 makespan。

02

观察

反例、Q-table、训练曲线与验证结果。

03

推理

LLM 分析原因并提出可证伪的单因素假设。

04

行动

修改代码和配置，执行测试、训练与验证。

05

记忆

保存反例库、实验注册表和 Git 历史。

06

停止条件

反例基本消除，或重新诊断后改进仍不收敛。

完整闭环观察 → 推理 → 行动 → 初筛 → 精筛 → 记忆与迭代
当前模型

Mk

在固定发现集运行，并记录全部候选动作。

↓
观察 · 反例挖掘

同状态分叉 + 反事实重放

比较当前所选动作与所有可行替代动作的最终 makespan，生成确认有害反例库 CEk。

反例判定

若所选动作相对最佳替代动作的归一化 regret ≥ 1%，则记为有害反例；若二者共享同一离散状态键，则说明状态表示发生信息丢失。

↓
推理 · LLM 诊断

从反例提出一个可证伪假设 Hk

分析反例与无害对照，只改变一个表示因素：相对化特征、替换弱信息、补充资源耦合上下文，或降低状态稀疏性。

↓

06 · 结论

四个研究点对应一条完整路线：
描述、求解、学习、改进。

描述建立多资源耦合约束的 PAS 调度模型
→
求解用元启发式高效搜索复杂解空间
→
学习用强化学习实现端到端联合决策
→
改进用 LLM Agent 构建反例驱动的自学习闭环

最终目标：构建兼具稳定性、泛化能力与持续自学习能力的智能调度模型，实现对动态扰动的快速响应，并迁移至不同制造系统与调度场景。

07 · 未来展望与下一步

下一阶段聚焦深度强化学习与 AI 驱动的自主调度。

近期

验证 LLM Agent 的持续改进能力

以反例驱动状态表示优化，验证 Agent 能否在保持整体调度性能的同时持续提升模型的泛化能力。

深度强化学习

从 Q 表走向可扩展的函数逼近

面向更多工件、资源与连续状态，研究图表示、注意力机制和约束感知的策略网络，同时保留可行性保证。

动态决策

学习对扰动快速响应的在线策略

把紧急订单、机器故障、随机加工与装卸时间纳入环境，研究无需从头优化的实时重调度。

AI 自学习

让 Agent 自动发现、验证并积累调度知识

将反例诊断、特征生成、实验设计与知识记忆连接起来，形成有证据约束的持续改进机制。

迁移与协同

跨产品、跨产线、跨系统迁移

结合迁移学习、元学习和多智能体协同，使策略能够适应不同 PAS 配置与其他多资源制造系统。
