01

我研究的，不是单台机器怎么工作。

我研究的是多个有限资源如何相互配合。一个看似更快的机器选择，可能让夹具长期占用；一次局部最优，也可能造成后续拥堵。这就是多资源调度的难点。

02

→

重点二 · LLM Agent

让强化学习发现：
自己遗漏了什么

强化学习有时会选错，不是因为没有训练，而是因为它看到的信息不够。LLM Agent 从错误案例中寻找缺失信息，提出新特征，再交给实验验证。

LLM 提建议实验做裁判
1找到错例

模型在哪些决策上看错了？

→
2提出假设

还缺少哪一个关键信息？

→
3重新实验

真的变好，还是只是看起来合理？

一个真实的研究片段

新特征消除了原来的错误，
但整体表现反而变差。

因此：不包装成成功拒绝晋级，继续寻找原因。
