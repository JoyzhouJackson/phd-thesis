# Yulu Zhou — PhD Research Portfolio

A responsive, dependency-free research website presenting two intertwined doctoral research trajectories:

- increasing problem complexity in multi-resource pallet automation system scheduling;
- increasing method generality from exact optimization to metaheuristics, reinforcement learning, and LLM-agent-assisted representation refinement.

## Local preview

Serve the directory with any static HTTP server, for example:

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.

## Deployment

The site is designed for GitHub Pages and contains no build step or external runtime dependency.
